# Практическая работа 10 - Итоговый проект

## Описание

Как сделать чтобы работало?
- Скачайте расширение Dart и Flutter в VSC
- Запустите через `F5` в удобном вам эмуляторе

## Цель

Разработать кроссплатформенное приложение на фреймворке Flutter с интеграцией сервисов Firebase, в котором реализованы: система аутентификации пользователей (вход и регистрация) с использованием Firebase Authentication, а также функционал для работы с постами (просмотр, добавление, редактирование и удаление) с хранением данных в Firestore. Посты должны содержать заголовок, текст и почту автора (с возможностью добавления даты и изображения), при этом список постов должен быть общим для всех авторизованных пользователей.

Более подробно про интерфейс и его критерии:
1. Общий дизайн и стиль (1 балл)

   • Приложение должно иметь единый стиль и цветовую палитру, соответствующую тематике проекта.

   • Использование шрифтов и иконок, которые обеспечивают хорошую читаемость и визуальную привлекательность.

   • Приложение либо должно быть адаптировано и корректно отображаться (без кнопки на пол экрана) на всех устройствах, либо должно делаться с ориентиром на конкретную платформу. Если вы делаете на Web, значит и интерфейс готовьте под Web и т.д.

2. Навигация (1 балл)

   • Реализация удобной и интуитивно понятной навигации между различными разделами приложения.

   • Использование навигационного меню (например, боковое меню или вкладки), которое всегда доступно пользователю.

   • Обеспечение возможности быстрого возврата на предыдущие экраны (например, через кнопку "Назад").

3. Формы ввода данных (1 балл)

   • Все формы должны быть простыми и удобными для заполнения, с ясными метками и подсказками для каждого поля.

   • Реализация валидации ввода данных (например, проверка формата электронной почты, обязательные поля).

   • Предоставление обратной связи пользователю в случае ошибок при заполнении форм (например, выделение полей с ошибками).

4. Отображение данных (1 балл)

   • Данные должны отображаться в удобном для восприятия формате (например, списки, карточки).

   • Возможность сортировки и фильтрации данных (если это уместно в рамках выбранной вами темы).

   • Реализация системы уведомлений об успешных действиях пользователя (например, сообщение о сохранении данных).

   • Уведомления должны быть ненавязчивыми и исчезать через несколько секунд или по клику.

## Вывод
В ходе выполнения работы было создано приложение, полностью соответствующее требованиям технического задания. Реализованы окна авторизации и регистрации с валидацией введенных данных и переходами между ними. Разработан главный экран для просмотра общего списка постов, а также функциональность создания, редактирования и удаления записей с полями согласно заданию. Данные пользователей и постов успешно синхронизированы с Firebase, что обеспечивает надежное хранение и доступ к информации. В результате поставленная цель достигнута, приложение готово к использованию и демонстрирует эффективное взаимодействие Flutter с экосистемой Firebase.
